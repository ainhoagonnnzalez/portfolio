03

Route 66

Desarrollo web · Juego

Desarrollo de un juego de carreras para navegador, realizado durante el bootcamp de Ironhack. El jugador elige uno de cuatro coches y cambia de carril con las flechas para adelantar rivales. Hay tres niveles, cada uno con un tiempo y un objetivo de adelantamientos. La partida incluye tres vidas, detección de colisiones, potenciadores de velocidad y objetos activables: cohete, escudo y nitro. Durante la carrera suena la música y, al terminar, se muestran los adelantamientos, la velocidad máxima y el tiempo restante.

HTML5 CSS3 JavaScript DOM ES Modules
